# ALBAZ MoonCalc Pro

**Version:** v0.10.8  
**Platform:** Windows x64  
**Type:** Standalone desktop astronomical application

## العربية

برنامج فلكي مكتبي مستقل لحساب ورسم إمكانية رؤية الهلال وفق أربعة معايير منفصلة:

- Yallop — يالوب
- Odeh — عودة
- SAAO
- Allawi — علاوي

### التنزيل والتشغيل

1. افتح قسم **Releases** في هذا المستودع.
2. نزّل الملف: `ALBAZ_MoonCalc_Pro_v0.10.8_Windows_x64.zip`.
3. فك الضغط كاملًا في مجلد جديد.
4. شغّل `ALBAZ_MoonCalc_Pro.exe` مع إبقاء مجلد `_internal` بجانبه.

> هذه النسخة تطبيق Windows وليست موقعًا يعمل عبر GitHub Pages أو المتصفح.

للتفاصيل العلمية راجع [README_AR.md](README_AR.md) ومستندات التدقيق داخل [docs](docs).

## English

ALBAZ MoonCalc Pro is a standalone Windows astronomical application for lunar-crescent visibility mapping using four isolated criteria: Yallop, Odeh, SAAO, and Allawi.

### Download and run

1. Open the repository **Releases** section.
2. Download `ALBAZ_MoonCalc_Pro_v0.10.8_Windows_x64.zip`.
3. Extract the complete archive into a new folder.
4. Run `ALBAZ_MoonCalc_Pro.exe` while keeping the `_internal` directory beside it.

> This release is a Windows desktop application, not a GitHub Pages website.

See [README_EN.md](README_EN.md) and the scientific audit documents in [docs](docs).
