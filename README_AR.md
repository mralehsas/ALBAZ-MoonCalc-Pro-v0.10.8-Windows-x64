# ALBAZ MoonCalc Pro v0.10.8

برنامج فلكي مكتبي مستقل لحساب ورسم رؤية الهلال وفق أربعة معايير منفصلة:

- يالوب Yallop
- عودة Odeh
- SAAO
- علاوي Allawi

## خريطة علاوي المطابقة للمصدر

عند اختيار **معيار علاوي** يستخدم البرنامج مسار صورة خاصًا مقفل المصدر لإعادة إنتاج خريطة برنامج علاوي المدقق، بدل عرضها بقالب MoonCalc الداكن العام.

المسار المعتمد يثبت العناصر الآتية:

- الخريطة الأساسية الفاتحة نفسها: محيط أزرق فاتح ويابسة كريمية وحدود دول واضحة.
- إسقاط Equirectangular بين خطي طول `180°W–180°E` وخطي عرض `80°S–80°N`.
- نطاق التلوين العلمي بين `60°S–60°N`.
- أبعاد المصدر `2048 × 950` وحدود الرسم الأصلية: يسار `88`، يمين `1960`، أعلى `59`، أسفل `891`.
- ألوان علاوي الرسمية: A أخضر داكن، B أخضر فاتح، C أصفر، D أحمر، X أسود، و`?` بلا تعبئة.
- شفافية خلايا اللون `82%` والفاصل الشبكي النسبي نفسه.
- علامة المدينة الحمراء واسمها بنفس صياغة الخريطة المرجعية.
- حد X الأسود مستخرج من حالة الاستحالة نفسها، مع تنعيم بصري ضيق لا يغيّر أي عقدة علمية.
- تصدير PNG وتقارير PDF يستخدمان المركب الأصلي مباشرة، دون إعادة تصوير مشهد الواجهة أو تغيير نسب الخريطة.

## محرك علاوي المقفل

يُحسب الحكم عند:

```text
وقت الرصد = غروب الشمس + (4/9 × مكث القمر)
```

ثم تُحسب الهندسة الطبوغرافية لمركزي الشمس والقمر:

```text
w  = نصف قطر القمر الظاهري × (1 − cos ARCL)
qA = w + ARCV/6 − 1.25
```

والتصنيف:

- `A`: qA ≥ 1
- `B`: 0 ≤ qA < 1
- `C`: −0.25 ≤ qA < 0
- `D`: qA < −0.25 أو ARCL < 4.5°
- `X`: الاقتران المركزي بعد الغروب أو المكث غير موجب
- `?`: تعذر الحل

عند اختيار علاوي يحدد البرنامج تلقائيًا شبكة **التحقق النهائي 10,800 خلية مركزية** لضمان صورة قريبة من الخريطة المرجعية وعدم ظهور خلايا كبيرة خشنة.

## البناء على Windows

أغلق أي نسخة قديمة من البرنامج ثم شغّل:

```text
BUILD_FULL_WINDOWS_ONE_CLICK.cmd
```

سكربت البناء يستخدم مجلدات عمل وإخراج فريدة ذات طابع زمني، ويمنع تعارض ملفات PySide6 المفتوحة مثل `icudtl.dat`.

## تصدير التقارير في v0.10.8

بعد نجاح الحساب تصبح أزرار تقارير يالوب وعودة وSAAO وعلاوي فعالة مباشرة. عند طلب التقرير، إذا لم تكن خريطة الموقع والتاريخ الحاليين جاهزة، يحسبها البرنامج تلقائيًا ثم يكمل إنشاء ملف PDF. يحفظ البرنامج المسار الأخير، ويعرض رسالة نجاح تتضمن المسار والحجم، ويوفر زرًا لفتح مجلد التقارير.

المجلد الافتراضي:

`Documents\ALBAZ MoonCalc Pro\Reports`

وفي حال تعذر الكتابة إليه يستخدم البرنامج مجلدًا احتياطيًا على سطح المكتب.
