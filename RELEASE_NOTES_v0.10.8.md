## Highlights

- Standalone Windows desktop application.
- Lunar-crescent visibility maps using Yallop, Odeh, SAAO, and Allawi criteria.
- Source-locked Allawi scientific/image path and validated 10,800-cell grid.
- Offline CesiumJS-based WGS84 3D presentation resources.
- PNG and PDF report export support described in the bundled documentation.

## Installation

Extract the complete ZIP archive and run `ALBAZ_MoonCalc_Pro.exe`. Do not move the executable away from its `_internal` directory.
